# Relational Dislocation Theory  
## 关系位错论

**Relational Dislocation Theory / 关系位错论** is a philosophical framework by **Mellow Jueran Wei / 魏珏然**.

Its central claim is:

> **A 出错了，不代表 A 错了。**  
> **When A fails, it does not mean A is wrong.**

Error does not always belong to the entity itself.  
Sometimes error emerges from the relation, interface, context, rhythm, and synchronization structure in which the entity is placed.

---

## Core Axiom

> **Error belongs to the relation, not the entity.**  
> **错误可能属于关系，而不属于实体。**

A tool, system, person, model, or body may appear to fail not because it is inherently broken, but because it has been placed into a misaligned relational structure.

---

## Main Idea

Relational Dislocation Theory argues that many failures should not be understood as isolated internal defects.

Instead, they may arise from misalignment between:

- entity and environment
- tool and task
- model and prompt
- body and rhythm
- person and institution
- interface and expectation
- system and feedback loop

In this framework, repair does not mean simply correcting an entity.  
Repair means rebuilding synchronization.

---

## Key Propositions

### 1. Tools are not right or wrong; they are fitted or misfitted.

工具本身没有绝对对错。  
它们只有是否适配当前任务、接口、语境与节律。

### 2. The interface layer is where dislocation occurs.

接口不是中立通道。  
接口会制造、放大或修复位错。

### 3. Repair is not correction; repair is rebuilding synchronization.

修复不是把 A 改成 B。  
修复是重建 A 与世界之间的同步条件。

## Application Areas

### LLM Hallucination

LLM hallucination is not only an internal model error.  
It often emerges between model, prompt, task boundary, user expectation, knowledge context, and verification interface.

### Human Cognition

Human cognitive error is not always caused by irrationality or individual defect.  
It may emerge from dislocation between person, language, institution, pressure, environment, and bodily rhythm.

### BCI-HRP Rhythm Therapy

In BCI-HRP, overload, numbness, anxiety, pain, or attention collapse can be understood as dislocations among body, qualia, rhythm, environment, and feedback systems.

Therapy is not symptom suppression.  
Therapy is rhythmic re-synchronization.

## Connection to Metacognition

Metacognition is not merely thinking about thinking.

In Relational Dislocation Theory, metacognition means recognizing the relational layer where error emerges.

> **元认知不是看见自己错了，而是看见错误发生在哪一层关系里。**  
> **Metacognition is not simply seeing that one is wrong; it is seeing at which relational layer the error emerges.**
